# My-site

Personal portfolio site for **Aklilu** — software engineering student in Mekelle, Ethiopia, and AI/tech content creator.

🔗 **Live site:** https://aklilut40-code.github.io/My-site

## About

This is a single-page portfolio built with plain HTML, CSS, and vanilla JavaScript — no frameworks, no build step. It covers:

- A short bio and background
- Current skills and tools (web development, Linux, content creation)
- The guides and bilingual (Tigrinya / English) content work I produce

## Tech

- HTML5 / CSS3
- Vanilla JavaScript
- Hosted for free with [GitHub Pages](https://pages.github.com/)

## Structure

```
My-site/
├── index.html   # the site itself
└── README.md    # this file
```

## Deployment

Pushed to `main` and served automatically via GitHub Pages (Settings → Pages → Deploy from branch → `main` / root).
